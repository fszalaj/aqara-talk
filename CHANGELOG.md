# Changelog

## 0.1.0

- Two-way audio bridge for Aqara G410, using an existing Frigate or go2rtc runtime.
- HACS installation, native camera selection and runtime/stream discovery.
- Automatic admin sidebar viewer using Advanced Camera Card or WebRTC Camera, with a copyable dashboard configuration.
- Setup diagnostics and generated runtime configuration, with camera, runtime and viewer installation guides.
- Configurable call duration through the Home Assistant UI, applied to the next call; single-caller exclusion and bounded cleanup.
- Advanced Camera Card call-start listening and microphone activation, with listening muted on hangup.
- Examples for dashboards, popups, View Assist and doorbell notifications.
- Home Assistant, frontend, offline bridge and package checks.
